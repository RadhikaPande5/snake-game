# 🐍 Snake Game

This is my recreation of the classic Snake Game using Python and the Turtle graphics module.

The idea was to bring back a tiny piece of nostalgia that many of us grew up with.

If you were the kind of person who would secretly grab your parent's Nokia, Motorola, or any random dabba phone just to beat your high score, you'll definitely relate. 😌

## Run the Game

1. Clone this repository.
2. Open your terminal and navigate to the cloned folder.
3. Run: python my_main.py

That's it.

You'll see your little snake moving around. Feed it, grow it bigger, try not to crash, and enjoy.

To be honest, I'm pretty sure most people don't need the rules or controls explained. If you've played the original Snake even once, your muscle memory will probably kick in immediately. 😄

Consider this your desktop version of the legendary Snake game.

Made with nostalgia, Python, and a lot of respect for the legendary keypad-phone Snake game... or should I say, our very own "Saanp Wala Game." 🐍❤️
